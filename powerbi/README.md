# Power BI

Esta pasta deve armazenar o dashboard final do projeto.

Arquivo planejado:

```text
powerbi/analise_jogos_steam.pbix
```

## Fontes para importar

Use os arquivos tratados em:

```text
data/processed/
```

Arquivos recomendados:

- `steam_games_clean.csv`;
- `steam_game_genres.csv`;
- `powerbi_genre_ratings.csv`;
- `powerbi_price_ranges.csv`;
- `powerbi_releases_by_year.csv`;
- `powerbi_top_developers.csv`;
- `powerbi_developer_ratings.csv`.

Nao importe o arquivo bruto `data/raw/steam_games.csv`.

## Paginas sugeridas

1. Visao geral do catalogo.
2. Avaliacoes por genero.
3. Preco versus avaliacao.
4. Evolucao dos lancamentos.
5. Desenvolvedoras em destaque.
