# Power BI

Esta pasta vai armazenar arquivos e anotacoes relacionadas ao dashboard em Power BI.

Sugestao de paginas do relatorio:

1. Visao geral do catalogo.
2. Avaliacoes por genero.
3. Preco versus avaliacao.
4. Evolucao dos lancamentos.
5. Desenvolvedoras em destaque.

Os arquivos tratados em `data/processed/` devem ser usados como fonte principal do dashboard.
